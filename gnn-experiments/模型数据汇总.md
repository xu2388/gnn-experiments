# 眼底影像GNN项目与数据集汇总.md

## 一、基础入门项目（易复现、代码结构清晰、适合入门）
### 1. PyTorch Geometric 官方视觉GNN示例（通用模板）
- **GitHub地址**：https://github.com/pyg-team/pytorch_geometric/tree/master/examples/vision
- **核心功能**：官方提供的Patch-GCN、超像素GNN图像分割/分类基础实现，包含完整的「图像转图结构」、GCN/GAT层、训练推理全流程
- **适配任务**：眼底血管分割、眼底图像分类（可直接替换眼底数据集）
- **配套公开数据集**：
  - DRIVE 眼底血管分割数据集：https://drive.grand-challenge.org/
  - STARE 眼底血管数据集：http://cecas.clemson.edu/~ahoover/stare/

### 2. Graph U-Net（GNN+U型结构分割基线）
- **GitHub地址**：https://github.com/HongyangGao/Graph-U-Nets
- **核心功能**：经典图U-Net实现，支持超像素建图+图卷积下采样/上采样，是医学图像GNN分割的通用基线模型
- **适配任务**：眼底血管二分类分割、眼底多区域分割
- **配套公开数据集**：
  - CHASE_DB1 眼底血管数据集：https://blogs.kingston.ac.uk/retinal/chasedb1/
  - HRF 高分辨率眼底数据集：https://www5.cs.fau.de/research/data/fundus-images/

### 3. DGCNN 动态图卷积（血管拓扑建模入门）
- **GitHub地址**：https://github.com/WangYueFt/dgcnn
- **核心功能**：经典动态图卷积网络，原生适配不规则点/拓扑结构，可直接用于血管骨架点、血管分叉点的图建模
- **适配任务**：眼底血管拓扑分割、动静脉血管分类
- **配套公开数据集**：
  - DRIVE-AV 动静脉标注子集：https://drive.grand-challenge.org/
  - HRF 高分辨率眼底数据集：https://www5.cs.fau.de/research/data/fundus-images/

## 二、SOTA级前沿项目（眼底专属、性能领先）
### 1. 动态特征图卷积眼底血管分割（DF-GCN）
- **GitHub地址**：https://github.com/liminyi-shanghai/Dynamic-GCN-Retinal-Vessel
- **核心功能**：专门针对眼底血管设计的动态图卷积模块，融合CNN纹理特征与GNN拓扑特征，解决细小血管断裂问题，分割精度优于纯UNet
- **适配任务**：眼底血管二值分割、细血管增强分割
- **配套公开数据集**：
  - DRIVE 数据集：https://drive.grand-challenge.org/
  - CHASE_DB1 数据集：https://blogs.kingston.ac.uk/retinal/chasedb1/

### 2. GAT 糖尿病视网膜病变分级（图分类任务）
- **GitHub地址**：https://github.com/liamheng/Retina-GNN-DR-Grading
- **核心功能**：基于病灶关系图的眼底疾病分级框架，先提取眼底病灶ROI作为节点，GAT建模病灶空间分布关系，最终输出DR分级（0-5级）
- **适配任务**：糖尿病视网膜病变分级、眼底图像疾病分类
- **配套公开数据集**：
  - IDRID 印度糖网数据集：https://ieee-dataport.org/open-access/indian-diabetic-retinopathy-image-dataset-idrid
  - Kaggle EyePACS 糖网数据集：https://www.kaggle.com/c/diabetic-retinopathy-detection/data

### 3. 血管拓扑感知GNN动静脉分割（AV-GNN）
- **GitHub地址**：https://github.com/rmaphoh/Retinal-AV-Segmentation-Graph
- **核心功能**：针对眼底动静脉交叉误分问题，构建血管拓扑图，GNN建模血管连通性与分叉关系，是动静脉分割方向的主流SOTA实现
- **适配任务**：眼底动静脉多分类分割、血管拓扑分析
- **配套公开数据集**：
  - DRIVE-AV 动静脉标注数据集：https://drive.grand-challenge.org/
  - HRF 高分辨率眼底数据集：https://www5.cs.fau.de/research/data/fundus-images/

### 4. 多尺度图网络OCT眼底分层分割（MGU-Net开源实现）
- **GitHub地址**：https://github.com/jiaxuanli97/MGU-Net
- **核心功能**：U-Net编码器中间插入多尺度GNN全局推理模块，专门适配眼底OCT图像的分层分割，可迁移至彩色眼底图像分割任务
- **适配任务**：眼底OCT分层分割、视盘/黄斑分割
- **配套公开数据集**：
  - Duke OCT 眼底数据集：https://people.duke.edu/~sf59/Srinivasan_BOE_2014_dataset.htm
  - REFUGE 青光眼眼底数据集：https://refuge.grand-challenge.org/
